# Magyarországi Vízvisszatartási Esemény- és Hírtérkép

Publikus interaktív webtérkép: https://vizmegtartas.github.io/

## Adatforrások és módszertan
- **Hivatalos közlemények és sajtóhírek:** Az Országos Vízügyi Főigazgatóság (OVF) és a 12 területi vízügyi igazgatóság (VIZIG) hivatalos portáljai, valamint megyei és országos sajtóforrások.
- **Térinformatikai alaprétegek:** VGT3 / VarGEO_alap vízügyi igazgatósági határok, hazai vízfolyások, tározók és holtágak.
- **Duplaszámolás kizárása:** Az azonos beavatkozásról szóló több forrás egyetlen kanonikus eseményhez van kötve, így az összesített térfogat minden eseményből csak egyszer számítódik.

Ez a repository kizárólag a statikus webtérkép publikálására szolgáló csomagot tartalmazza.
